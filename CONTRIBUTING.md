# Contributing

UseSteady is a developer CLI. Interactive steps wait for approval. `--yes` and break-glass skip per-step prompts.

## Issues

Use GitHub issues for bugs and questions that can be public.

For vulnerabilities or possible misuse, email support@usesteady.dev. See SECURITY.md.

## Scope

This repository is the public product home: license, notice, package metadata, CLI distribution material, examples, demos, and changelog.

Private Core implementation, Ops, and research records are not in this repository.
